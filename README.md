# 冒険の書（quest-log）

メンターから受けた課題を「クエスト」として受け渡し、成長を RPG のように記録するためのリポジトリです。
記録は GitHub Pages で表示しています：https://mother-load.github.io/quest-log/

## 使い方

### メンター：クエストを出す
1. 「Issues」→「New issue」→「クエスト（メンターからの課題）」を選ぶ
2. タイトルの「【クエスト】」の後ろに課題名を書き、内容・報酬（経験値）・スキル・難易度・期限を入れて作成

### 本人：提出する
- そのクエストの Issue に、成果物の URL や感想をコメントで書く

### メンター：クリアにする
- ひとことコメントを書いてから、Issue を「Close issue」（完了）で閉じる
- 閉じたのがメンターのときだけクリアになり、経験値が入ります。そのコメントは「メンターの言葉」として記録に残ります
- 「Close as not planned」で閉じると、中止扱い（経験値なし）になります

### 本人：自主トレを記録する
- 「New issue」→「自主トレ（自分で取り組んだこと）」で書いて、自分で閉じる（10〜30 経験値）

## ルール
- レベル L に必要な累計経験値：50 × L × (L − 1)（Lv2 = 100、Lv3 = 300、Lv4 = 600 …）
- メンターは `config.json` の `mentors` に GitHub ユーザー名を書きます。空のときは、このリポジトリの協力者（Collaborator）として書き込んだ人をメンターとみなします
- リポジトリの持ち主・協力者以外が立てたクエストは数えません

## 仕組み
- Issue が作られたり閉じられたりするたびに、GitHub Actions が `scripts/build-data.mjs` で Issue を集めて `data.json` を作り、`site/` の画面と一緒に公開します
- 記録は `data.json`（公開ページの「記録データ」）と Issue そのものに残るので、別の場所へ移すときはこれを持っていけます
- 見た目の確認用に、架空のデータで表示するデモ（`?demo`）があります
